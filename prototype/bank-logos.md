# საქართველოს ბანკების ლოგოები — წყაროები

ეროვნული ბანკის რეესტრი (2026-10-12): 18 ლიცენზირებული კომერციული ბანკი — https://nbg.gov.ge/en/licensed-commercial-banks

ლოგო აიღე **ბანკის ოფიციალური საიტიდან** (ჰედერის ლოგო ან „მედია / პრესისთვის / Brand" გვერდი), არა სურათების ძიებიდან. საუკეთესოა SVG ან გამჭვირვალე PNG. ატვირთვა: ადმინი → მთავარი → ორგანიზაციები → ✎ → „ლოგო" → „ატვირთვა".

საჯაროდ ლოგოს გამოყენებამდე საჭიროა ბანკის თანხმობა (პარტნიორებისგან — ხელშეკრულებისას).
